# 古诗内容数据规范 v0.3

## 1. 内容生命周期

每条诗词及题目必须处于以下状态之一：

`draft` -> `in_review` -> `published` -> `archived`

- 只有 `published` 内容可提供给学习端。
- Excel、爬取或外部来源先进入 `staged_poems`，审核通过后才可合并到 `poems`。
- 所有修改必须保留来源字段；错误或版权不清晰的媒体不可发布。
- 首期由单一内容审核人完成审核、发布、归档和回滚；每项操作必须记录操作人、时间和原因。
- 发布、归档或回滚不可覆盖历史数据，必须生成可追溯的内容版本快照。

## 2. 诗词必填字段

| 字段 | 规则 |
|---|---|
| `slug` | 英文小写、连字符；稳定且不随标题修改，例如 `wang-lushan-pubu`。 |
| `title` | 标准题名；保留必要篇目标识，如 `饮酒·其五`。 |
| `author` / `dynasty` | 采用统一作者、朝代表，不写在正文中。 |
| `body` | 每句一行；保留中文标点；不混入翻译、注释。 |
| `pinyin_lines` | JSON 数组，长度必须等于正文行数；每项只对应一行原文。学习端默认隐藏，由拼音按钮按需显示。 |
| `brief_analysis` | 80-180 字，适合“读诗小笺”。 |
| `detailed_analysis` | 250-800 字，解释结构、关键字词、修辞和情感。 |
| `creation_background` | 80-300 字；无法确认时明确标为“背景待考”。 |
| `source_reference` | 版本、教材或可信参考来源。 |
| `textbook_edition` | 必填教材归属；首期默认苏教版 2026，并支持人教版 2026。相同诗可关联多个教材版本。 |

## 3. 分类要求

每首发布诗至少具备：

1. 一个学习库：小学必备、课外推荐或进阶学习。
2. 一个年级或明确标为课外/进阶。
3. 一个题材、一个体裁、一个时代。
4. 至少一个“古诗与物”意象标签。
5. 至少一个教材版本归属；苏教版 2026 和人教版 2026 的年级、篇目与教学重点可分别维护。

可选关联包括历史事件、诗歌流派、作者画像、关联诗词和音频。

## 4. 媒体与版权

- 每首发布诗必须有一张经审核的 `detail_background`，并可选一张 `cover`。
- 可使用网络来源图片、课本插图或 AI 生成图。首期仅限内网浏览，审核人须记录来源、用途、审核人和版权状态；不要求保存可再发布证据，且内容不得对公网公开或二次分发。
- 使用 AI 生成图时，`copyright_status` 标注为 `generated`；课本插图需记录出版社、版本、页码及许可/使用依据。
- 每首发布诗必须具备一条 `audio_reading` 标准普通话朗诵音频。录入时记录朗读者、版本、时长与逐句时间轴；学习端需支持播放、暂停、重新播放和播放失败提示。

## 5. 题目规范

- 每首可进行深度学习的诗至少有 5 道已发布选择题，以支持每次随机抽取 3-5 题。
- 每题 3-4 个选项，且仅一个正确项。
- 必须提供解析，说明正确理由而不是仅给答案。
- 题目覆盖字词、画面/情感、表达手法或背景中的至少两类。
- 学习端对同一题连续答错 3 次后，提示是否查看正确答案与题目解析；题目编辑时须提供该解析。

## 6. Excel 导入规则

当前 `古诗.xlsx` 为原始内容来源。导入工具只写入 `staged_poems`：

- 自动提取标题、朝代、作者和正文。
- 缺少标题、作者或正文时写入 `validation_errors`。
- 导入不直接覆盖 `poems`；编辑审核后才执行合并。
- 当前 Excel 的全部古诗均可作为首期发布基线。需要补齐默认隐藏的逐行拼音、解析、背景、教材/多维分类、审核通过的媒体、标准普通话朗诵音频和至少 5 道已发布题后，才允许发布。
